# 用户协议与安全声明（API Key 使用）

更新日期：2026-02-23

本协议用于说明：当你在 Dweb Video Studio 中填写第三方 AI 服务（例如 DeepSeek、Gemini）的 API Key 时，我们如何使用、如何存储、有哪些风险以及你的权利与义务。

请在继续使用“填写 API Key 并保存”的功能前，仔细阅读并确认你理解并同意以下条款。

---

## 1. 名词解释

- **API Key**：由第三方 AI 服务提供商签发的访问凭证，具备调用权限与计费能力，性质等同于密码。
- **本软件/我们**：指 Dweb Video Studio 客户端及其随附的本地后端服务（Django）。
- **第三方服务**：指 DeepSeek、Gemini 等模型服务提供商的远程接口。

---

## 2. 你提供 API Key 的目的

你填写 API Key 的唯一目的，是让本软件能够代表你向第三方服务发起模型调用请求，以完成字幕理解、内容生成、图像生成等功能。

---

## 3. 我们如何使用你的 API Key

1. **仅用于发起第三方模型请求**：API Key 会被用于构造对第三方服务的 HTTP 请求鉴权信息。
2. **不会将 API Key 上传到我们的远程服务器进行存储或转发**：本软件的设计目标是不经过我们自建的远程中转服务。
3. **第三方服务不可避免**：当你使用 AI 功能时，请求会发送到对应的第三方服务提供商（远程服务），并受其隐私政策、计费规则与安全策略约束。

---

## 4. 我们如何存储你的 API Key（加密存储说明）

为降低明文配置泄露风险，本软件会在本地 Django 数据库中保存你的 API Key，并使用对称加密进行加密存储（“加密静态存储”）。

你需要理解：

- 加密存储可以降低“误操作/普通程序读取数据库文件”造成的泄露概率。
- **加密存储不能对抗“电脑已被入侵/恶意软件有权限读取进程内存或程序配置”的情况**。

---

## 5. 你需要自行承担并管理的风险

1. **计费与额度风险**：任何获得你 API Key 的人都可能消耗你的额度。我们建议你在第三方服务后台设置额度限制与告警。
2. **本机安全风险**：如果你的电脑存在恶意软件或被他人获取系统权限，API Key 可能被窃取。
3. **第三方服务风险**：第三方服务可能存在服务波动、策略调整、计费变化等情况。

---

## 6. 我们的免责声明

1. 我们不对因 API Key 泄露、误用或第三方服务异常造成的费用损失承担保证责任。
2. 我们会尽力降低本地明文暴露风险，但不承诺在所有威胁模型下都能保证 API Key 绝对安全。
3. 因第三方服务政策变化导致的不可用、限流、封禁、计费争议等，需由你与第三方服务提供商自行处理。

---

## 7. 你的建议安全操作

- 使用“专用 Key”：为本软件单独创建 Key，不与其他应用共用。
- 设置额度与告警：设置每日/每月限额，开启消耗告警。
- 避免公开：不要在录屏、截图、日志、仓库中暴露 Key。
- 可随时吊销：如怀疑泄露，请第一时间吊销并更换。

---

## 8. 同意方式

当你在设置页点击“保存”并在弹窗中勾选“我已阅读并同意”后，即表示你已阅读、理解并同意本协议。
