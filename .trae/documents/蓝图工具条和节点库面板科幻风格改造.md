# Plan: 蓝图工具条 & 节点库面板 科幻风格改造

## Summary

对 AI 工作流蓝图页面左上角工具条（`BlueprintProjectToolbar.vue`）和双击空白处弹出的节点库面板（`DwebCanvasNodeSearchMenu.vue`）进行科幻/赛博未来（Sci-Fi/Cyber Futuristic）风格改造，统一使用项目已有的主题变量（`--wf-*`、`--theme-accent`、`--sqp-*`）和设计语言（玻璃底、L括号、翡翠辉光、DOM 粒子等）。

---

## Current State Analysis

### 1. BlueprintProjectToolbar.vue（工具条）
**路径**: `src/ui/WorkFlow/BlueprintProjectToolbar.vue`

- 当前使用 `--vscode-*` 系列 CSS 变量（`--vscode-border`、`--vscode-fg`、`--vscode-hover-bg`、`--vscode-shadow` 等）
- `aiwf-floating-rail__status-dot` 使用硬编码颜色 `#6ee7b7`（未保存时 `#f6c177`）
- 背景使用 `color-mix(in srgb, var(--dweb-defualt-dark) 92%, transparent)`
- 主按钮（`is-primary`）使用 `#4cb1ff` 蓝色，与项目翡翠主色调不统一
- 整体为扁平化设计，无科幻装饰元素
- popover 和 dialog 边框使用 `var(--vscode-border)`，无辉光效果

### 2. DwebCanvasNodeSearchMenu.vue（节点库面板）
**路径**: `src/ui/UIComponent/DwebCanvasNodeSearchMenu.vue`

- 当前使用 `--wf-*` 系列变量（`--wf-surface-raised`、`--wf-border`、`--wf-text`），已部分对齐主题
- 面板背景 `var(--wf-surface-raised)`，边框 `var(--wf-border)`，无特殊装饰
- 激活 Tab 使用 `--wf-primary` 翡翠色，符合主题，但面板整体缺乏科幻细节
- 无 L 括号、无粒子层、无 HUD 风格装饰

---

## Proposed Changes

### 改造原则

1. **工具条**：改用 `--theme-accent` 翡翠色作为主色调，替换硬编码颜色
2. **节点库面板**：增加科幻 L 括号装饰、HUD 扫描线叠加、顶部辉光条
3. **两者通用**：玻璃拟态背景（`backdrop-filter: blur`）、翡翠辉光边框、统一的圆角风格（2px）
4. **背景遮罩**：`node-skins.css` 中已有 `--wf-overlay-bg` 定义，保持一致

## CSS Token 依赖

改造将复用以下已定义的主题 token（来自 `theme-tokens.css` 和 `node-skins.css`）：

- `--theme-accent: #1f9d84` / `--theme-accent-hover: #27b99c` — 主翡翠色
- `--theme-bg-primary`、`--theme-bg-secondary`、`--theme-text-primary`、`--theme-text-muted` — 背景/文字
- `--wf-surface-raised`、`--wf-surface-base` — 面板背景
- `--wf-border`、`--wf-border-subtle`、`--wf-primary` — 边框/主色
- `--wf-control-bg-hover`、`--wf-text` — 控件状态
- `--aiwf-color-accent` — 暖金色（running/warn 状态）
- `--aiwf-color-danger` — 红色（error/delete 状态）

无需新增 CSS 变量，直接复用现有 token。

## Assumptions & Decisions

1. **工具条 `is-primary` 按钮颜色**：从蓝色 `#4cb1ff` 改为翡翠色 `--theme-accent`，与项目整体风格一致。
2. **工具条未保存状态点颜色**：从 `#f6c177` 改为暖金色 `--aiwf-color-accent`（#e5b567），与节点 running 态颜色呼应。
3. **节点库面板 L 括号**：与节点 `node-skins.css` 中的 `wf-node-bracket` 风格一致，使用 `border` 画 L 形。
4. **遮罩背景**：保持透明模糊（`backdrop-filter`），但叠加翡翠色半透明层，使面板更融入科幻背景。
5. **动画曲线**：统一使用 `cubic-bezier(0.22, 0.61, 0.36, 1)`（缓动效果）。
6. ** Reduced Motion**：通过 CSS `@media (prefers-reduced-motion: reduce)` 禁用增强动画。

## Verification Steps

1. 打开 AI 工作流蓝图页面，确认工具条左上角显示，带 L 括号装饰和翡翠辉光
2. 点击工具条各按钮（项目/资源/节点库/添加节点），确认 popover/dialog 显示正常，样式一致
3. 双击蓝图空白区域，确认节点库面板弹出，带 HUD 扫描线和 L 括号装饰
4. 在节点库面板中搜索和切换 Tab，确认交互效果和翡翠色辉光
5. 切换暗色/亮色主题，确认颜色正确适配（通过 `color-mix` 和 CSS 变量自动混合）
6. 开启浏览器 `prefers-reduced-motion` 特性，确认动画被正确降级
