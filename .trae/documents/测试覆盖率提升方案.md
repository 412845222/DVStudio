## 假设与决策

1. **测试策略**: 单元测试优先于集成测试
2. **Mock 策略**: 使用 Vitest 的 vi.fn() 和 vi.mock() 进行依赖隔离
3. **覆盖率阈值**: 核心模块（validate, instantiate）需要 85%+，其他模块 60%+
4. **不测试的文件**:
   - WebGL 渲染层 (DwebCanvasGL.ts) - 需要真实 WebGL 环境
   - 复杂的第三方集成 (ComfyUIBridgeService) - 需要完整后端
   - Store 的完整 Vue 集成 - 已有基本测试

## 验证步骤

1. 运行 `npm run test:coverage` 验证所有测试通过
2. 检查覆盖率报告，确认各模块达标
3. 运行 `npm run typecheck` 确保类型安全
4. 如有需要，调整阈值配置 (vitest.config.ts)
