# 项目概述 (Project Overview)

## 1. 项目简介
DVStudio (Dweb Video Studio) 是一个基于 WebGL2 的视频编辑与 AI 工作流蓝图项目。它旨在将传统的视频时间轴编辑与现代的 AI 生成能力（如 ComfyUI）深度结合，提供一站式的视频创作体验。

## 2. 核心能力

### 2.1 AI 工作流蓝图 (AI Workflow Blueprint)
- **定位**: 节点化的 AI 任务编排工具。
- **功能**: 
  - 资源导入与管理。
  - 剧情与分支编排（Story Nodes）。
  - 连接本地或远程的 ComfyUI 服务进行推理。
  - 输出媒体（图片/视频）的回流与预览。
- **入口**: `src/views/AIWorkflow.vue`

### 2.2 视频编辑器 (Video Editor)
- **定位**: 基于时间轴和关键帧的 2D 视频动画编辑器。
- **功能**:
  - 舞台节点（矩形、文字、图片、线条）的所见即所得编辑。
  - 时间轴关键帧与缓动曲线控制。
  - AI 对话辅助（生成布局、批量修改样式、生成滤镜）。
- **入口**: `src/views/VideoStudio.vue`

## 3. 目标用户与使用场景
- **创作者**: 使用 AI 工作流快速生成素材，并在视频编辑器中进行精细化排版和动画制作。
- **开发者**: 基于现有的 WebGL2 引擎和节点系统，扩展新的渲染能力或 AI 接入能力。
